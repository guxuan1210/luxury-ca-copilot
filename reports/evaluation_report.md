# D. Evaluation Report（评估报告）

> 本报告基于 `evaluation/results.csv`、`evaluation/summary.json`、`evaluation/defect_log.csv` 与 `data/generated_outputs.csv` 生成。所有数字为实际运行结果，未达标的案例如实披露。

## D.1 Evaluation Procedure（评估流程）

1. **L1 规则检查**（`src/validator.py`）：对全部 50 个案例的 150 条输出做确定性检查——恰好 3 条、非空中文、策略正确、无重复、折扣/优惠关键词与过度感叹号软提示。
2. **L2 LLM-as-Judge**（`evaluation/evaluator.py`）：固定 Rubric（`judge_prompt.md`），`temperature=0`，对每条输出按五项指标打分（1–5），每组三条做 Diversity 评价，并单独标记 `factual_error` 与 `boundary_violation`。
3. **L3 人工复核**：对全部 Critical / Major 缺陷、每场景至少 3 个案例、Judge 不确定案例做人工确认。

加权质量分：`Q = 0.25·Relevance + 0.20·Personalization + 0.20·Brand Consistency + 0.20·Naturalness + 0.15·Context Fidelity`。

## D.3 Scenario-level Analysis（场景级分析）

**生日节日 / 产品推荐 / 活动邀请（强项）**：V2.0 平均分均 ≥ 4.56。生日祝福与活动邀请的信息充分、目的单一，模型能稳定产出得体且个性化的内容；产品推荐在 V2.0 中提升最大（+0.181），主要来自差异度要求让三条候选真正分化为「简洁推荐 / 关系式分享 / 开放提问」。

**价格异议（最弱，V2.0 4.112）**：本场景受「规则 10（不得对定价原因/成本/留香/浓度做未经证实的因果推断）」约束最强。客户问「凭什么这么贵」时，模型被禁止编造理由，只能复述香调与品类事实并表达尊重，导致相关性偏低、三条候选易趋同（如 TC046 三候选均以「理解顾虑 + 复述香调 + 尊重决定」收尾）。这是**合规与相关性的固有张力**：V2.0 用「宁可不够有说服力，也不编造」换取了事实安全。

**售后关怀（V2.0 4.131，回落）**：信息不足类案例（如 TC025「购买信息不完整」、无历史）只能产出泛化问候，评分偏低；此类回落部分源于 Judge 非确定性（TC025 由 4.03 降到 3.43，但输出本身仍得体），非实质退化。

**唤醒（V2.0 4.316）**：V1.0 唯一的边界违规（TC033，客户明确要求减少营销联系）在 V2.0 被规则 11 修复——由「问候 + 隐含香氛话题引导」改为「纯问候 + 明确尊重停止联系意愿」，该案例从 3.69 提升到 4.24。

## D.4 Qualitative Examples（定性示例）

**高质量示例（V2.0 价格异议 TC049，事实错误被修复）**：客户要求「内部价」。V1.0 曾断言「目前为统一价格、暂无内部价格」这一未经证实的定价政策；V2.0 改为：

> 「关于价格，目前我没有可确认的内部价格或额外优惠，也希望能以更透明的方式与您沟通……是否入手完全尊重您的节奏。」

既不虚构折扣、也不虚构「统一定价」政策，只表达「我无法确认」，是符合事实约束的得体应对。

**低质量示例（V2.0 价格异议 TC046，div=3）**：客户问「这个价格凭什么这么贵」。三条候选均围绕「理解顾虑 + 复述 Silk Peony 香调（牡丹/荔枝/白麝香）+ 尊重您决定」收尾，几乎未正面回应「凭什么」，差异度低（3/5）、加权分 3.38。根因是规则 10 禁止编造定价理由，模型缺乏一个被授权的、事实性的价值陈述模板，只能兜底复述。

**边界修复示例（唤醒 TC033）**：V2.0 的 warm_personalized 候选：

> 「知道您希望减少营销联系，因此这条信息只作问候，不带任何推荐。愿您生活安适……若您希望不再收到消息，请直接告诉我。」

从「软性再营销」转为「明确尊重边界」的纯问候，Judge 边界违规由 True 变为 False。

## D.6 Limitations（局限）

1. **LLM-as-Judge 的非确定性**：尽管 `temperature=0`，思考型模型（`deepseek-v4-pro`）的推理路径仍存在随机性，同一输出的评分可能在不同运行间略有波动。已通过固定 Rubric + 人工抽样复核缓解。
2. **Judge 与生成器同源**：生成与评审使用同一底层模型，可能存在系统性盲区；L3 人工复核是最终依据。
3. **规则检查的语义盲区**：L1 只能识别表面关键词（如「折扣」），无法识别隐晦的事实编造，需依赖 L2/L3。
4. **单品牌单品类**：结论局限于香氛品类与单一品牌语气，泛化到其他奢侈品类的有效性未经验证。
5. **评分尺度主观性**：1–5 分制本身带有主观成分，通过 Rubric 与实例锚定降低歧义，但无法完全消除。
